# How you persuade

Drag a dot inside a triangle with ethos (credibility), pathos (emotion) and logos (logic) at its corners. The same ask, "give me a raise", rewrites itself to match your mix, and the boss reacts.

Lean too far into any one corner and it stops working. The boss only says yes near the middle.

Styled after Attic red-figure pottery: black gloss ground, clay orange, and the added white and yellow ochre painters used on top. Greek key borders, Greek corner labels.

## Built with

- React 18 (no build step, `React.createElement`)
- GSAP 3.13: Draggable for the dot, SplitText for the pitch, tweens for the meter
- GFS Neohellenic and Didact Gothic (SIL Open Font License 1.1)

Everything loads from jsDelivr. Open `index.html` in a browser, nothing to install.
